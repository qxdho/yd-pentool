# UI 重构方案

> 决策记录：2026-11-24
> 目标：**去掉繁琐操作、直观好看、亮/暗双主题**

## 已确定的决策

| 议题 | 结论 |
|---|---|
| 深色模式 | **必须做**，且是完整主题（不是简单反色） |
| 右上角窗口按钮 | **删除**：适配屏幕 / 放大 / 缩小，全部去掉 |
| 阶段划分 | 8 步 → **3 阶段**（准备固件 / 改写并校验 / 回灌验证） |
| 默认模式 | **每阶段确认**（安全优先），另提供「一键到底」开关 |
| 术语 | 专有名词保留英文（`hosts`、`MTP`、`ADB`、`MD5`），其余中文化（`endpos` → 分段边界） |

## 一、现状问题

| # | 问题 | 证据 |
|---|---|---|
| 1 | 8 步太碎，实际只有 3 件事 | 左侧 8 个序号 |
| 2 | 同一动作多入口 | 「下载全量包」在卡片里和更多菜单里都有 |
| 3 | 手动字段多 | `endpos 列表`、镜像路径、JSON 路径 |
| 4 | 日志常驻 260px，纯噪音 | 底部黑框 |
| 5 | 前置条件不可见 | 管理员/hosts/热点/防火墙藏在日志里 |
| 6 | 失败无指引 | 只有一行 `[!] ...` |
| 7 | 按钮无层级 | 一屏 4–5 个同权重按钮 |
| 8 | 高级功能混在主流程 | 443 探测、代理抓包、hosts 冲突提示 |
| 9 | 单文件 1488 行 | `lib/main.dart` |
